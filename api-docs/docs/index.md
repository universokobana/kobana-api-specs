## O que é a Kobana

A Kobana é um conjunto de serviços oferecidos em forma de sistema web e APIs que permite a automação de operações bancárias e o consumo de serviços financeiros de bancos brasileiros diretamente na conta da sua empresa ou do seu cliente.

**A Kobana não é um banco, nem conta digital e nem intermediador.** Nós não substituímos os serviços bancários — simplificamos o consumo dos serviços oferecidos pelos bancos por meio de uma API única que se conecta a vários bancos.
