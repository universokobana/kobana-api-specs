Arquivos de especificação da API

Mantemos publicamente os arquivos de especificações em diversos formatos para que você possa baixar e usar em seu software favorito.

Mantemos os arquivos nos seguintes formatos:

- Swagger no formato OpenAPI 3.1
- Coleção do Postman ([saiba mais sobre o suporte ao Postman](/api/overview/postman))

| Tipo | Versão da API | Formato | Arquivo |
| --- | --- | --- | --- |
| OpenAPI 3.1 | v1 | JSON | [kobana-api-v1\_0-openapi-3\_1.json](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v1_0/kobana-api-v1_0-openapi-3_1.json) |
| OpenAPI 3.1 | v1 | YAML | [kobana-api-v1\_0-openapi-3\_1.yaml](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v1_0/kobana-api-v1_0-openapi-3_1.yaml) |
| OpenAPI 3.1 | v2 | JSON | [kobana-api-v2\_0-openapi-3\_1.json](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v2_0/kobana-api-v2_0-openapi-3_1.json) |
| OpenAPI 3.1 | v2 | YAML | [kobana-api-v2\_0-openapi-3\_1.yaml](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v2_0/kobana-api-v2_0-openapi-3_1.yaml) |
| Coleção do Postman | v1 | JSON | [kobana-api-v1\_0-postman-collection.json](https://github.com/universokobana/kobana-api-specs/blob/main/postman/v1_0/kobana-api-v1_0-postman-collection.json) |
| Coleção do Postman | v2 | JSON | [kobana-api-v2\_0-postman-collection.json](https://github.com/universokobana/kobana-api-specs/blob/main/postman/v2_0/kobana-api-v2_0-postman-collection.json) |

Os arquivos estão disponíveis em um projeto no Github.
