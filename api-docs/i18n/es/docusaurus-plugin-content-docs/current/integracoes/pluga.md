### ¿Qué es Pluga?

[Pluga](http://pluga.io) integra las herramientas web que tu empresa más usa, creando una comunicación inteligente entre ellas. Y lo mejor: ¡sin necesidad de escribir una sola línea de código!

Con Pluga conectas tu cuenta de Kobana con las principales herramientas de Brasil y del mundo, automatizando procesos operacionales (y tediosos) de tu empresa.

### Kobana en Pluga

Para ver todas las posibilidades de integración de Kobana en Pluga, accede a:

[https://pluga.co/ferramentas/boleto\_simples/](https://pluga.co/ferramentas/boleto_simples/)

### Comenzando a usar Pluga

Para crear una cuenta en Pluga, sigue estos pasos:

- Accede a [https://manage.pluga.co/#/signup](https://manage.pluga.co/#/signup)
- Completa con los datos solicitados
- Marca la casilla "Acepto los términos de uso"
- Haz clic en "Cadastrar"

¡Listo! Ahora puedes crear una nueva automatización en Pluga haciendo clic en la herramienta Kobana.

La dirección directa para crear automatizaciones después de iniciar sesión es:

[https://manage.pluga.co/#/ferramentas/boleto\_simples](https://manage.pluga.co/#/ferramentas/boleto_simples)

### Creando una Automatización

Pluga ofrece automatizaciones listas entre los productos.

Para cada tipo de evento hay una automatización disponible.

Debes elegir la automatización deseada y configurarla en tu cuenta.

Cada automatización solicita una configuración diferente.

Vamos a ejemplificar con una de las automatizaciones disponibles que se llama:

[A cada pago de boleto aprobado en Kobana, se genera una nota fiscal electrónica de servicio en NFe.io](https://pluga.co/automatizacoes/boleto_simples-nfe_io-pagamento-aprovado-gerar-nota-fiscal/)

Para configurar esta automatización sigue los pasos:

#### 1. Haz clic en "Hacer esta automatización"

#### 2. Conecta las dos herramientas

#### 3. Completa los datos para la emisión de la Nota Fiscal

#### 4. Verifica el mensaje que la automatización está funcionando

#### 5. Recibirás un email confirmando la integración
