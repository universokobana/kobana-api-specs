### ¿Qué es Zapier?

[Zapier](http://zapier.com) es un servicio en línea para conectar aplicaciones y automatizar tareas. Kobana está en Zapier y esto significa que puedes integrar con más de 3.000 aplicaciones disponibles.

### Kobana en Zapier

Para ver todas las posibilidades de integración de Kobana a través de Zapier, accede a:

[https://zapier.com/apps/kobana/integrations](https://zapier.com/apps/kobana/integrations)

- Última versión: 2.0.0
- Última modificación: 25/04/2020

### Comenzando a usar Zapier

Para crear una cuenta en Zapier, sigue estos pasos:

- Accede a [https://zapier.com/sign-up/](https://zapier.com/sign-up/)
- Completa tu Primer Nombre (First Name), Último Nombre (Last Name), Email y Contraseña (Password)
- Haz clic en "Sign Up"
- En la siguiente pantalla, haz clic en la "x" en la esquina superior derecha
- Haz clic en "No, thanks"

¡Listo! Ahora puedes crear un nuevo Zap haciendo clic en el botón "Make a New Zap".

### Entendiendo Zapier

Zapier se basa en los Zaps, que son configuraciones de integración entre dos sistemas. El primer sistema es el que genera un evento (trigger) y el segundo sistema es donde se ejecuta una acción (action).

El sistema que genera el evento lo llama Trigger App y el sistema donde se ejecuta la acción lo llama Action App.
