Archivos de especificación de la API

Mantenemos públicamente los archivos de especificaciones en varios formatos para que puedas descargar y usar en tu software favorito.

Mantenemos los archivos en los siguientes formatos:

- Swagger en formato OpenAPI 3.1
- Colección de Postman ([obtén más información sobre el soporte de Postman](/api/overview/postman))

| Tipo | Versión de la API | Formato | Archivo |
| --- | --- | --- | --- |
| OpenAPI 3.1 | v1 | JSON | [kobana-api-v1\_0-openapi-3\_1.json](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v1_0/kobana-api-v1_0-openapi-3_1.json) |
| OpenAPI 3.1 | v1 | YAML | [kobana-api-v1\_0-openapi-3\_1.yaml](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v1_0/kobana-api-v1_0-openapi-3_1.yaml) |
| OpenAPI 3.1 | v2 | JSON | [kobana-api-v2\_0-openapi-3\_1.json](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v2_0/kobana-api-v2_0-openapi-3_1.json) |
| OpenAPI 3.1 | v2 | YAML | [kobana-api-v2\_0-openapi-3\_1.yaml](https://github.com/universokobana/kobana-api-specs/blob/main/swagger/v2_0/kobana-api-v2_0-openapi-3_1.yaml) |
| Colección de Postman | v1 | JSON | [kobana-api-v1\_0-postman-collection.json](https://github.com/universokobana/kobana-api-specs/blob/main/postman/v1_0/kobana-api-v1_0-postman-collection.json) |
| Colección de Postman | v2 | JSON | [kobana-api-v2\_0-postman-collection.json](https://github.com/universokobana/kobana-api-specs/blob/main/postman/v2_0/kobana-api-v2_0-postman-collection.json) |

Los archivos están disponibles en un proyecto en Github.
