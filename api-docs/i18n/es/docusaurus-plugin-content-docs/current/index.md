## Qué es Kobana

Kobana es un conjunto de servicios ofrecidos en forma de sistema web y APIs que permite la automatización de operaciones bancarias y el consumo de servicios financieros de bancos brasileños directamente en la cuenta de tu empresa o de tu cliente.

**Kobana no es un banco, ni cuenta digital ni intermediario.** No reemplazamos los servicios bancarios — simplificamos el consumo de los servicios ofrecidos por los bancos a través de una API única que se conecta a varios bancos.
