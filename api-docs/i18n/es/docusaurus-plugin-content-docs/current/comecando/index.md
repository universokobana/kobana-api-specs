# ✅ ¿Qué es Kobana?

Kobana es un conjunto de servicios ofrecidos en forma de sistema web y APIs que permite la automatización de operaciones bancarias y consumo de servicios financieros de bancos brasileños directamente en la cuenta de tu empresa o de tu cliente.

# 🛑 ¿Qué NO es Kobana?

Kobana no es un banco, ni cuenta digital ni intermediario. No reemplazamos los servicios bancarios. Simplificamos el consumo de los servicios ofrecidos por los bancos a través de una API única que se conecta a varios bancos.

# 💡 Ejemplos de uso de la API

- Actualización del saldo y extracto en el sistema ERP
- Automatización de cobros por boleto bancario y Pix
- Pago de empleados y colaboradores
- ¡y mucho más!
