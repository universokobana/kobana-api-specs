Las bibliotecas pueden ayudarte a integrar rápidamente tu sistema con Kobana.

Bibliotecas oficiales mantenidas por Kobana para acelerar tu integración. Código limpio, bien documentado y listo para producción.

## Funcionalidades Comunes

Todos los SDKs oficiales incluyen:

- **Autenticación Simple** - Configura una vez, usa en todas las solicitudes.
- **Manejo de Errores** - Excepciones tipadas para cada tipo de error de la API.
- **Reintentos Automáticos** - Reintentos automáticos con exponential backoff para errores de red.
- **Paginación Facilitada** - Iteradores y helpers para navegar resultados paginados.
- **Tipado Completo** - Definiciones TypeScript, type hints (Python), PHPDoc.
- **Logging Integrado** - Modo debug para inspeccionar solicitudes y respuestas.
