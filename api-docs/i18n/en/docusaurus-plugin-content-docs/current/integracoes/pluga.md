### What is Pluga?

[Pluga](http://pluga.io) integrates the web tools your company uses most, creating intelligent communication between them. And the best part: without needing to write a single line of code.

With Pluga you can connect your Kobana account with the leading tools in Brazil and around the world, automating operational (and tedious) processes in your company!

### Kobana on Pluga

To see all integration possibilities for Kobana on Pluga, visit:

[https://pluga.co/ferramentas/boleto\_simples/](https://pluga.co/ferramentas/boleto_simples/)

### Getting Started with Pluga

To create a Pluga account, follow these steps:

- Visit [https://manage.pluga.co/#/signup](https://manage.pluga.co/#/signup)
- Fill in the requested information
- Check the box "I accept the terms of use"
- Click "Sign Up"

Done! Now you can create a new automation in Pluga by clicking on the Kobana tool.

The direct address to create automations after logging in is:

[https://manage.pluga.co/#/ferramentas/boleto\_simples](https://manage.pluga.co/#/ferramentas/boleto_simples)

### Creating an Automation

Pluga offers ready-to-use automations between products.

For each type of event there is an available automation.

You need to choose the desired automation and configure it in your account.

Each automation requires different configuration.

Let's illustrate with one of the available automations:

[Each time a boleto payment is approved in Kobana, an electronic invoice for service is generated in NFe.io](https://pluga.co/automatizacoes/boleto_simples-nfe_io-pagamento-aprovado-gerar-nota-fiscal/)

To configure this automation follow these steps:

#### 1. Click "Do this automation"

#### 2. Connect the two tools

#### 3. Fill in the information to issue the Invoice

#### 4. Confirm that the automation is working

#### 5. You will receive an email confirming the integration
