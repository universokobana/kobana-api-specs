### What is Zapier?

[Zapier](http://zapier.com) is an online service for connecting applications and automating tasks. Kobana is on Zapier, which means you can integrate with over 3,000 available applications.

### Getting Started with Zapier

To create a Zapier account, follow these steps:

- Visit [https://zapier.com/sign-up/](https://zapier.com/sign-up/)
- Fill in your First Name, Last Name, Email and Password
- Click "Sign Up"
- On the next screen, click the "x" in the top right corner
- Click "No, thanks"

Done! Now you can create a new Zap by clicking the "Make a New Zap" button.

### Understanding Zapier

Zapier is based on Zaps, which are integration configurations between two systems. The first system is the one that generates an event (trigger) and the second system is where an action is executed (action).

The system that generates the event is called the Trigger App and the system where the action is executed is called the Action App.
