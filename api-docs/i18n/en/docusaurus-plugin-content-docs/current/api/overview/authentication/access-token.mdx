To make requests to the API using your own account, simply use the `Access Token` available in the system interface in the `Integrations > API > API Token` menu.

:::info[Check the environment]

The token is different between the sandbox and production environments.

:::

## Valid Request

Here's an example of a request to test if the token is working.

Assuming your `Access Token` is **xxxxxxxxxxxxxxxxxxxxxxxx**

<Tabs>
<TabItem value="curl" label="Shell">

```bash
curl -i \
-H "Authorization: Bearer xxxxxxxxxxxxxxxxxxxxxxxx" \
-H 'Content-Type: application/json' \
-H 'User-Agent: MyApp (myapp@example.com)' \
-X GET 'https://api-sandbox.kobana.com.br/v1/userinfo'
```

</TabItem>
<TabItem value="ruby" label="Ruby">

```ruby
BoletoSimples.configure do |c|
  c.access_token = 'zjuio96wkixkzy6z98sy'
end

BoletoSimples::Extra.userinfo
```

</TabItem>
<TabItem value="php" label="PHP">

```php
BoletoSimples::configure(array(
  "access_token" => 'zjuio96wkixkzy6z98sy'
));

BoletoSimples\\Extra::userinfo();
```

</TabItem>
</Tabs>

## Invalid Request

Here's an example of a request when the token is invalid.

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl -i \
-H "Authorization: Bearer tokeninvalido" \
-H 'Content-Type: application/json' \
-H 'User-Agent: MyApp (myapp@example.com)' \
-X GET 'https://api-sandbox.kobana.com.br/v1/userinfo'
```

</TabItem>
<TabItem value="ruby" label="Ruby">

```ruby
BoletoSimples.configure do |c|
  c.access_token = 'tokeninvalido'
end

BoletoSimples::Extra.userinfo
```

</TabItem>
<TabItem value="php" label="PHP">

```php
BoletoSimples::configure(array(
  "access_token" => 'tokeninvalido'
));

```

</TabItem>
</Tabs>
