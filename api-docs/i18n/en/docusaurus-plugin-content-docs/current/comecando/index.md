# ✅ What is Kobana?

Kobana is a set of services offered in the form of a web system and APIs that allows the automation of banking operations and consumption of financial services from Brazilian banks directly in your company's or client's account.

# 🛑 What Kobana is not?

Kobana is not a bank, nor a digital account, nor an intermediary. We do not replace banking services. We simplify the consumption of services offered by banks through a single API that connects to several banks.

# 💡 Examples of API usage

- Update balance and statement in ERP system
- Automation of collections via bank slip and Pix
- Payment of employees and collaborators
- and much more...
